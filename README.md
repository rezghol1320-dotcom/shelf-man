# Shelf Man Auto Catalog

این نسخه برای ورود مرتب کالاها ساخته شده است.

## روش کار
- `products.json` کنار `index.html` قرار می‌گیرد.
- سایت هنگام باز شدن، کاتالوگ را می‌خواند و کالاهای جدید را به صورت خودکار اضافه می‌کند.
- برای کالاهای موجود، بارکد معیار اصلی جلوگیری از تکراری شدن است.
- از داخل سایت می‌توان CSV یا JSON هم وارد کرد.
- خروجی CSV نیز دارد.

### قالب JSON
[
  {
    "name": "نام کالا",
    "brand": "برند",
    "category": "دسته‌بندی",
    "barcode": "123456789",
    "price": 100000,
    "image": "https://example.com/image.jpg"
  }
]

برای همگام‌سازی واقعی با منبع افق کوروش، کافی است مرحله بعدی تولید/به‌روزرسانی `products.json` از منبع مجاز و قابل دسترس را به GitHub Pages وصل کنیم.
